# Nica Reklama Landing Page

One-page landing for the advertising agency **nica reklama**, built on Bootstrap 5.

## Features
- Responsive hero section with a call-to-action.
- Services grid, company video, and stats section.
- Gallery of completed projects and a newsletter sign-up block.
- Team showcase and contact-focused footer.

## Tech Stack
- HTML5 + Bootstrap 5.3
- Bootstrap Icons
- Custom CSS (`28/style.css`)

## Project Structure
```
28/
├── index.html      # main page
├── style.css       # additional styling
└── img/            # images (backgrounds, illustrations)
```

## Getting Started
1. Clone the repository or download the archive.
2. Open `28/index.html` in your browser (double-click or serve via a local server such as XAMPP).
